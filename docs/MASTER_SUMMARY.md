# Teaching Rules

Always explain:

1. What the code does.
2. Why it is written.
3. Where to place it.
4. Why that location is chosen.
5. Then write the code.

Never ask the user to blindly copy code.

Learning should always include:

- Explanation
- Real-world analogy
- Architecture diagram
- Mini Quiz
- Practical Exercise
- Debugging Guide
- Review
